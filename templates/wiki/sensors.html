A signal describes an actual observation. Add sensors you have; the game rewards varied readings rather than manufactured values.

Signal format

{"kind":"scalar","strength":0.6,"value":{"metric":"temp_c","n":21.5}}

This is an example shape, not a source of live readings. Use your sensor’s measured value and a documented normalization for strength between 0 and 1.

Listener adapters

WB_SIGNALS_CMD runs a command whose stdout is a JSON array of signals. For example, point it at a script you wrote for your connected sensor:

export WB_SIGNALS_CMD='python3 /absolute/path/read_sensor.py'

WB_ENVIRON_URL can read a JSON environment endpoint with temperature, humidity, pressure, lux or noise. WB_INTERVAL is a fallback retry interval; server cadence takes priority.

Local GUI adapters

The full engine can run up to ten configured shell sensor commands. This is disabled by default; enable WAVEBEAST_ALLOW_EXEC=1 only for trusted local commands. The standalone app supplies native sensors through its host bridge; availability varies by platform.

Sensor contract

Use the engine’s GET /capabilities for kinds and normalization conventions. RF, Bluetooth, Wi-Fi, location and scalar readings can influence a scan. The strongest type-bearing sensor influences the elemental identity; entropy and coherence shape the individual roll.

Different beasts from familiar places

Each new beast encounter mixes your signals with a fresh host-generated seed. Repeating a sweep at home, or scanning the same barcode again, can discover a different name and creature. Sensors still influence element and roll quality. Saved beasts keep their original names and sprites. New creatures use readable procedural names, twelve anatomy families and coordinated pixel-art palettes.

Auto and manual sweeps

Standalone Auto mode attempts one background scan every 30 minutes. Its timer survives restarts and toggling Auto; manual sweeps retain their normal five-minute cooldown. In the standalone app and local GUI, pending sightings appear in Scan results below the scanner. Sightings and auto activity each show the latest 100 entries, in up to five pages of 20. The Beasts tab holds your collection.
