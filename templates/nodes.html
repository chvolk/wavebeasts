Connect a node

A node just assembles a ScanBundle and POSTs it with its token. It doesn't need the full engine:

curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/snapshot \
  -H "X-WB-Node-Token: <your node token>" \
  -H "Content-Type: application/json" \
  -d '{"schema":"wavebeast.scanbundle","v":1,"signals":[
        {"kind":"wifi","strength":0.7,"value":{"rssi":-50}},
        {"kind":"scalar","strength":0.6,"value":{"metric":"lux","n":300}} ]}'

Or run the standalone WaveBeast app / the wavebeast-node script and paste the token.
